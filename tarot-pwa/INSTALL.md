# 📱 iPhoneへのインストール - 簡単ガイド

## 最速インストール方法（5分）

### ステップ1: ファイルをアップロード（3分）

**Netlifyを使う場合（一番簡単）**

1. https://app.netlify.com/drop にアクセス
2. zipファイルを解凍
3. 解凍したフォルダ全体をドラッグ&ドロップ
4. URLが表示されます（例：`https://random-name-123.netlify.app`）

**GitHub Pagesを使う場合**

1. https://github.com/new にアクセス
2. リポジトリ名を入力（例：`tarot-app`）
3. 「Public」を選択
4. 「Create repository」をクリック
5. 「uploading an existing file」をクリック
6. zipファイルを解凍したフォルダの中身を全てドラッグ&ドロップ
7. 「Commit changes」をクリック
8. Settings → Pages → Source を「main」に設定
9. 数分後、URLが表示されます（例：`https://username.github.io/tarot-app/`）

### ステップ2: iPhoneにインストール（2分）

1. **Safari**アプリで、ステップ1で取得したURLを開く
2. 画面下部の**共有ボタン**（□に↑のマーク）をタップ
3. 下にスクロールして**「ホーム画面に追加」**をタップ
4. 名前を確認（変更可能）
5. 右上の**「追加」**をタップ

✅ 完了！ホーム画面に紫色のアイコンが追加されます

## 🎉 使い方

ホーム画面のアイコンをタップすると、本物のアプリのように全画面で起動します！

### 初回起動時
- カード画像をダウンロードするため、少し時間がかかります
- 一度開けば、以降はオフラインで使えます

### 占い方
1. 質問を入力（任意）
2. 「初期カードを引く（3枚）」をタップ
3. 「次のカードを引く」を何度もタップ
4. 展開完了→アドバイスカードと解釈が表示

## ❓ よくある質問

### アイコンが表示されない
→ 必ず**Safari**で開いてください。Chrome等では動きません。

### オフラインで使えない
→ 一度オンラインで開いて、全てのカードを表示させてください。

### アップデートしたい
→ Safariで直接URLを開いて再読み込み→アプリを再起動

### アンインストールしたい
→ ホーム画面のアイコンを長押し→「Appを削除」

## 🆘 問題が起きたら

1. iPhoneを再起動
2. Safariのキャッシュをクリア
3. 上記の手順を最初からやり直す

## 📧 サポート

問題が解決しない場合は、以下の情報をメモしてください：
- iPhoneのモデル（例：iPhone 13）
- iOSのバージョン（設定→一般→情報で確認）
- エラーメッセージ（あれば）
