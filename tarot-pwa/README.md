# CBDマルセイユタロット占い PWA版

目線展開スプレッドとアドバイスカード機能を持つタロット占いアプリのPWA（Progressive Web App）版です。

## 📱 iPhoneへのインストール方法

### 方法1: Webホスティング経由（推奨）

#### ステップ1: ファイルをホスティング

以下のいずれかのサービスに全ファイルをアップロード：

**GitHub Pages（無料・簡単）**
1. GitHubにリポジトリを作成
2. このフォルダの全ファイルをアップロード
3. Settings → Pages → Sourceを「main branch」に設定
4. 数分後にURLが発行されます（例：`https://username.github.io/tarot-app/`）

**Netlify（無料・ドラッグ&ドロップ）**
1. https://www.netlify.com/ にアクセス
2. 「Add new site」→「Deploy manually」
3. このフォルダをドラッグ&ドロップ
4. 即座にURLが発行されます

**Vercel（無料）**
1. https://vercel.com/ にアクセス
2. 「Add New」→「Project」
3. このフォルダをアップロード
4. 自動デプロイ

#### ステップ2: iPhoneにインストール

1. **Safari**で発行されたURLを開く
2. 画面下部の**共有ボタン**（四角に上矢印）をタップ
3. **「ホーム画面に追加」**をタップ
4. アプリ名を確認して**「追加」**をタップ

✅ ホーム画面にアイコンが追加されます！

### 方法2: ローカルサーバー経由（開発者向け）

```bash
# Pythonを使う場合
python3 -m http.server 8000

# Node.jsを使う場合
npx http-server -p 8000
```

その後、iPhoneのSafariで `http://[あなたのPCのIPアドレス]:8000` にアクセスして、上記のステップ2を実行。

## 🎯 PWAの機能

### ✅ できること

- **ホーム画面から起動** - 本物のアプリのように使える
- **フルスクリーン表示** - ブラウザのUIが隠れて没入感アップ
- **オフライン動作** - 一度開けばインターネット不要
- **高速起動** - キャッシュされているので即座に起動
- **アプリっぽい見た目** - アイコンとスプラッシュ画面

### 📦 インストール後のファイルサイズ

- 約5MB（タロットカード画像78枚含む）
- 初回のみダウンロード、以降はオフライン可能

## 🔮 使い方

1. **「初期カードを引く（3枚）」**をタップ
2. **「次のカードを引く」**を繰り返しタップ
   - 1タップにつき1枚ずつカードが展開
3. **展開完了**
   - 🎯 アドバイスカードが自動計算・表示
   - スプレッド全体の解釈が表示

## 📊 アドバイスカード

過去・現在・未来の3枚から自動計算：
- 計算式：`(過去番号 + 現在番号 + 未来番号) ÷ 22の余り`
- 余りが0の場合は愚者（LE MAT）

## 🛠️ 技術仕様

- **動作環境**: iOS 11.3以降のiPhone/iPad
- **オフライン対応**: Service Workerによるキャッシュ
- **固定グリッド**: 15列×2行（-7～+7列）
- **画像**: 78枚のCBDマルセイユタロット
- **ストレージ**: 約5MB

## 🔄 アップデート方法

アプリを更新したい場合：
1. Safariでホスティング先のURLを直接開く
2. ページを再読み込み（下に引っ張る）
3. Service Workerが新バージョンをキャッシュ
4. アプリを閉じて再起動

## ❓ トラブルシューティング

### アイコンが表示されない
- iOSは152x152以上のアイコンが必要です
- `icons/icon-152.png` が存在するか確認

### オフラインで動かない
- 一度オンラインで開いてキャッシュさせる必要があります
- Safariの設定でService Workerが有効か確認

### カードが表示されない
- `images/` フォルダが正しくアップロードされているか確認
- F12（デスクトップ版Safari）でコンソールエラーを確認

### 「ホーム画面に追加」が出ない
- 必ず**Safari**を使用してください（Chrome非対応）
- HTTPSまたはlocalhostでアクセスしているか確認

## 🎨 カスタマイズ

### アイコンの変更
`icons/` フォルダ内のPNG画像を差し替えてください。

### テーマカラーの変更
`manifest.json` の `theme_color` と `background_color` を編集。

### アプリ名の変更
`manifest.json` の `name` と `short_name` を編集。
